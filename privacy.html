Política de privacidad

Drive OneDrive Sync es una herramienta de uso personal que utiliza rclone y las APIs de Google Drive y OneDrive.

Acceso a datos

La aplicación solicita acceso a archivos de Google Drive para realizar copias entre carpetas seleccionadas.

Uso de datos

Los archivos se transfieren entre las cuentas de almacenamiento configuradas por el usuario. No se venden datos ni se utilizan para publicidad.

Almacenamiento y seguridad

Las credenciales OAuth se almacenan localmente y como secretos protegidos de GitHub Actions. Los archivos se procesan durante las transferencias sin crear un repositorio público de su contenido.

Revocación de acceso

El usuario puede revocar las autorizaciones desde la configuración de seguridad de Google y Microsoft.
